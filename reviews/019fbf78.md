# Review: `arena/019fbf78-celup-lab`

## Scope and delta

Tip `875aa4b` is the later analytical-deblur experiment. It implements method 3 as a 2×2 bilinear-projected linear deblur and carries earlier analytical changes: shape-consistent mapping, contrast gating, optional safety-gate bypass, and comparison configurations. It also adds 13 binary comparison sheets plus real-image sheets (23 files, +2,204/−119).

## Comparison

- It is the later alternative to `019fbfb9`, which only adds the first `-D analytical` version and lossless-sheet output. Prefer this branch over `019fbfb9` if evaluating analytical deblur at all.
- It branches after v4.9.9 WIP `5d5f7a8`, but not after `019fba18` tip `18df5b2`; the final tangent-oriented pole correction is absent. Thus it must not be described as a superset of `019fba18`.
- It has the same staircase/gradient goals as `019fba14` but attacks them through a new autodeblur method rather than general resampler changes.

## Review finding

**Experimental candidate; do not merge wholesale.** “By construction” claims and safety-gate bypasses warrant adversarial tests rather than acceptance on selected sheets. The branch is a useful successor experiment because it explicitly replaces the first analytical design, but it has large committed binary artifacts and lacks the final v4.9.9 pole fix.

## Required integration checks

Port method 3 as an opt-in mode only. Compare against both current master and `019fba18` on existing stair/corner/scale tests, intentional smooth gradients, thin strokes, alpha, and real art. Require no default-path regression and define semantics for strength/gating before exposing it.
