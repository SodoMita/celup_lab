# Review: `arena/019fbfb9-celup-lab`

## Scope and delta

Tip `1293c23` adds the first `-D analytical` mode and updates the comparison-sheet generator to emit lossless WebP/split large combined sheets. It is the smallest functional candidate: 2 files, +41/−4. The analytical mode is described as a whole-image, four-color linear-gradient push with inverted strength and no case-specific safety gates.

## Comparison

- `019fbf78` is the clearly later analytical-deblur line: it replaces/refines the method with contrast gating, shape-consistent mapping, and a final 2×2 bilinear-projected implementation. This branch is not an ancestor of it because both diverge at master, but it is functionally superseded as the earlier design.
- `019fba18` is a separate, more mature fit-based autodeblur continuation; this early analytical method does not include its tangent-oriented evidence correction.
- The lossless/splitting sheet functionality is useful independently, but it is entangled with the analytical configuration changes in the same small patch.

## Review finding

**Do not merge the analytical implementation.** Its lack of safety gates and its early status make `019fbf78` the better comparison candidate. Consider the sheet-output code separately if maintainers need reproducible lossless reports; it should be tested with oversized sheets and documented output naming.

## Integration option

Take neither by default. If reporting output is desired, isolate only the WebP/splitting generator hunk. Evaluate `019fbf78` rather than this branch for the analytical algorithm.
