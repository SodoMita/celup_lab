# Review: `arena/019fba12-celup-lab`

## Scope and delta

Tip `a0ea21f` removes references to `superxbr` and `jinc2_bilateral`, while adding standalone xBR/xBRZ sources and headers plus scripts and result documents. Snapshot delta: 27 files, +1,916/−536. It also removes all checked-in source images and the two autodeblur notes, and carries local WebP headers.

## Comparison

- `019fbf57` is a descendant of this tip, then reintroduces/extends `jinc2_bilateral` and adds `jinc2_auto`; therefore this branch's stated removal is not a durable project direction.
- `019fbcda` similarly adds xBR/xBRZ and WebP headers while changing autodeblur behavior, so the supporting build/source layout overlaps but is not identical.
- `019fba0d` has the same undesirable note deletion without any compensating resampler work.

## Review finding

**Do not merge the branch wholesale.** The xBR/xBRZ extraction may be useful, but the branch simultaneously deletes fixture images and documentation and makes an architectural choice that the later Jinc2 branch reverses. The result documents are not a substitute for automated regression coverage.

## Integration option

If xBR/xBRZ is wanted, port only those implementation files and dispatch/build changes into a clean master worktree, preserve the existing images/docs, and add compile + mode smoke tests. Otherwise prefer no action.
