# Review: `arena/019fbf57-celup-lab`

## Scope and delta

Tip `1618485` adds `jinc2_auto`: a self-supervised 2× downscale proxy selects Jinc2 WB/STR settings, with a hardness penalty intended to avoid stair-stepping on pixel art. It follows `019fba12` and reintroduces/extends `jinc2_bilateral`, its tuning knobs, real-image sheet scripts, and scale-test coverage. Snapshot delta: 30 files, +2,484/−540, including deletion of several existing images and historical notes.

## Comparison

- This is the successor to `019fba12`; it reverses that branch's removal of Jinc2-bilateral, so `019fba12` should not be merged first.
- Unlike `019fba18`/`019fba1b`/`019fbcda`/`019fbf78`, it is an optional resampling mode, not an autodeblur-model modification. It can be evaluated and integrated independently.
- It has the same problematic support-file pattern as `019fba12`: duplicate WebP headers, xBR sources, scripts, and deletion of checked-in images.

## Review finding

**Candidate only if Jinc2 is a desired supported mode.** The proxy objective is a coherent, testable idea and the branch states an explicit diagonal-stair improvement. But the feature introduces auto-tuning complexity and must be benchmarked for runtime, determinism, and bad selections. Do not use generated comparison images as acceptance evidence.

## Required integration checks

Port Jinc2 implementation and the focused scale test into master without deleting assets/docs. Test deterministic output, time/memory on large inputs, natural photographs, pixel art, transparent edges, and explicit manual WB/STR overrides. Ensure help text makes auto-selection and fallback behavior clear.
