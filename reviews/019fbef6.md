# Review: `arena/019fbef6-celup-lab`

## Scope and delta

Tip `eaedb4d` is a tuning/diagnostic line. Its final functional change is `CELUP_CAPFLOOR`, defaulting to 0.6, described as the existing v4.9.2 behavior. It also introduces opt-in `-T` texture gain, a regression harness, diagnosis documents, comparison reports, sheet generators, and generated evidence images (14 files, +1,109/−3).

## Comparison

- It is a peer comparison of `019fba18`, not a descendant: the two diverge at the master snapshot. Its own history reports head-to-head sheets but cannot establish compatibility with the v4.9.9 tangent changes.
- It is much narrower in core intent than `019fba18`, `019fba1b`, and `019fbf78`: it adds knobs/tuning rather than replacing the deblur model.
- It addresses visual artifacts like the other autodeblur lines, but its environment-variable control is less discoverable and reproducible than a documented CLI parameter.

## Review finding

**Potential small port only; do not merge the branch wholesale.** The cap-floor default is intentionally behavior-preserving, making it low-risk if implemented cleanly. `-T` and its measurement harness deserve separate review. The branch otherwise consists substantially of generated evidence and private diagnosis artifacts, which should not be promoted as product changes.

## Required integration checks

Port each functional feature separately. Verify default output is bit-identical (or document any expected difference), test several cap-floor values, add CLI/help or explicit environment documentation, and run the regression harness against master fixtures. Keep generated sheets out of the functional PR.
